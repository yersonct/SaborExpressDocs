# Ejemplos de verificación y mantenimiento

Autor: Yerson Stiven Cuellar Rubiano; ficha: 3145555. Estos archivos son **ejemplos de referencia**, no parches ni pruebas ejecutadas. Están diseñados para ser copiados en un entorno de desarrollo bajo control, con base de datos sintética y credenciales de prueba. **NO** se incorporan a repositorios de aplicaciones automáticamente.

- `inventario-repositorios.ps1`: obtiene el SHA y confirma estructura, sin cambios de archivos.
- `smoke-api-publica.ps1`: consulta solo un recurso público, con URL configurable.
- `check-configuration.example.md`: inventario de variables sin valores secretos.
- `consulta-conceptual.sql`: ilustración de relaciones; NO DDL físico ni migración.
- `SECURITY-TESTS.md`: escenarios adversariales para una futura suite automatizada.
