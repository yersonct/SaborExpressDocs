# Base de datos

Este directorio incorpora un **inventario inicial verificable**, no un volcado de esquema. Para completar los tres marcadores de posición anteriores (SQL, DER PDF y relaciones DOCX): ejecutar generación de script EF Core con proveedor real, revisar claves foráneas/índices en migraciones y exportar un ERD de la base validada. **No ejecutar un SQL fabricado sin verificación.**

Fuente adicional existente en backend: `Analisis/SaborExpress_Diccionario_Datos.docx` (documento de referencia que debe revisarse contra migraciones actuales).

El archivo `database-schema.sql` es informativo y NO se debe ejecutar como esquema.
