La auditoría mide once vistas administrativas con viewport fijo y datos sintéticos.

Esta evidencia no es un run remoto de CI, integración con API real, estudio con usuarios, auditoría automatizada WCAG completa ni medición de dispositivos móviles. Los tiempos dependen de equipo, navegador y carga local. Las cifras no deben presentarse como KPI institucional o de producción.
